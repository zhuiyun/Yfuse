# 动画与弹窗优化（2026-09-08）

基线为 `4d5c4662`。代码在独立工作树 `.worktrees/playback-perf`，分支 `codex/motion-performance-20260908`。

## 实现

| 区域 | 改变 |
| --- | --- |
| 导航 | 导航栏宽度只改变裁剪外壳，内部标签保留最终宽度；取消重复尺寸动画。根页面切换使用有界的统一时长，搜索进场选择不会被无关重组覆盖。 |
| 轮播 | 指示器固定 48 dp 点击区域，滑动进度只在绘制阶段读取。背景颜色只重绘背景；主题和语义强调色每次换图更新一次。 |
| 可读性 | 用 sRGB 分量上下界证明整段背景渐变与目标正文颜色保持至少 4.5:1 对比度；不安全、隐藏或减少动画时立即切换目标色。 |
| 点击与焦点 | 焦点环缓存几何并只重绘透明度；按下和释放使用各自回弹参数，取消倾斜时归零。收藏光圈不参与尺寸测量，快速切换或中断后恢复稳定状态。 |
| 隐藏页面 | 骨架、服务器刷新、贴纸、启动预览停止无效时钟。启动页完全覆盖时暂停底层绘制，进入后台后结束欢迎动画。 |
| 现有弹窗 | Slide/Touch 直接更新图层；其他效果保留内容缓存，共用同一进度的几何结果，按效果类别直接分发。海报叠层仅在来源或尺寸变化时重新记录；减少重构切片、Bloom 方向等重复计算。 |

搜索交接、播放器提示、列表补位、刷新真实结果、说明展开和图片加载的具体行为见 [体验补充实施记录](APP_MOTION_OPPORTUNITIES_20260908.md)。

新增“趣味小物”组，弹窗总数从 33 增至 38：

- 纸飞机投递：折纸轮廓沿轻微弧线展开，纸飞机细节掠过上沿。
- 风铃轻摆：从上沿展开，两次衰减轻摆后归位。
- 拍立得冲印：先展开出片口，再向下露出正文，边缘细光逐渐消失。
- 拉链解封：拉头向下，两侧逐渐展开。
- 票根展开：票头先显现，正文沿齿边展开，票边细节随后收起。

新效果每帧只绘制一次内容，复用遮罩 Path，不创建位图、额外着色器或循环动画。变换在进度 0.88 前归位，装饰在 0.90 清除，遮罩在 0.92 完全展开；终态直接绘制完整内容。所有样式沿用统一关闭、中断和减少动画行为。

## 验证方法

设备为 Samsung SM-G973U，Android 9 / API 28，60 Hz。使用独立测试包 `com.yfuse.playbackperf`，同一新测试 APK 对比保存的基线应用 APK 和当前应用 APK。窗口帧指标从真实 Dialog Window 收集，入口通过实际触摸海报打开，包含有效海报来源；每个样式预热后再测量进场及退出。

报告 `FrameMetrics.TOTAL_DURATION` 的帧耗时及超出刷新周期的帧数，首次绘制单独计数。这里的超预算帧不是显示系统实际丢帧数；debug 构建、旧款单机与短时重复结果不能替代手机/平板的 release 长时性能矩阵。

实现依据：Compose 官方建议把高频状态推迟至[布局或绘制阶段](https://developer.android.com/develop/ui/compose/performance/phases)读取；窗口指标定义见 [FrameMetrics](https://developer.android.com/reference/android/view/FrameMetrics)。

## 弹窗窗口帧指标

比较使用同一个测试 APK。每轮每种样式先额外预热一次，再执行 10 次开关；预先约定舍弃前 5 次，保留第 6–10 次。基线 A3/A4 和核心优化 C1/C2 各两轮，每种样式每个版本保留 10 次有效开关。表中 p50/p95 是每次开关相应分位数的中位数，单位 ms；超预算比例按所有保留的非首次绘制帧合计。

| 样式 | 基线/优化帧数 | p50 基线→优化 | p95 基线→优化 | 超预算比例基线→优化 |
| --- | --- | --- | --- | --- |
| Lift | 198 / 200 | 10.249 → 9.362 | 19.755 → 18.119 | 12.63% → 12.00% |
| Slide | 226 / 229 | 9.064 → 9.827 | 18.463 → 18.363 | 10.62% → 12.23% |
| Touch | 227 / 228 | 10.292 → 10.558 | 17.225 → 18.077 | 14.98% → 10.53% |
| PosterMorph | 229 / 227 | 9.913 → 9.384 | 18.564 → 18.610 | 13.97% → 9.25% |
| Reconstruct | 218 / 216 | 10.546 → 9.857 | 17.688 → 18.035 | 12.84% → 14.35% |
| Mosaic | 227 / 224 | 10.954 → 10.020 | 18.772 → 18.417 | 17.62% → 15.18% |

总计由 183 / 1325 帧超预算变为 162 / 1324 帧（13.81% → 12.24%），但不同样式结果混合，Slide 和 Reconstruct 的超预算比例上升，不能据此声称每一种弹窗都更快。所有保留循环共各 60 个首次绘制帧另行计数，FrameMetrics 回调丢弃报告数为 0。短样本不构成统计显著性或全设备流畅度保证。

A3 首次尝试等待关闭超时，A4 首次尝试触摸 UP 注入失败，两轮各重跑一次才得到完整有效记录；无效运行未进入统计。早期较短探索结果，以及未采用的常驻焦点绘制节点方案，也不混入此表。
