## 新增的用户流程

| 项目 | 入口与行为 |
| --- | --- |
| 状态胶囊 | 导航栏上方汇总下载、投屏和一起看；可进入下载管理、暂停/重试下载、控制投屏、返回房间。沿用导航进出动画，隐藏导航不会销毁已打开的操作弹窗。投屏时间变化不会逐帧刷新整个胶囊。 |
| 智能片单 | 搜索页保存关键词、服务器、媒体库、类型、年份、类型标签、观看状态和排序；首页与媒体库首页显示固定片单。打开后查询当前服务器数据，支持无关键词筛选及分页。最多 40 个规则，可取消固定和删除；读取损坏时保留原始数据并拒绝覆盖。 |
| 桌面续播/追剧组件 | Android 桌面组件使用本地进度和缓存标题，提供续播与追剧详情入口。后台刷新不拉取服务器进度；旧账户被移除后不会跳入其他账户。布局可调整大小，最小高度 180dp。 |
| 元数据编辑 | 详情 → 更多 → 编辑元数据与图片。Emby/Jellyfin 支持标题、简介、TMDB ID；Plex 支持标题、简介。可预览和应用服务器提供的海报/背景图候选。需要当前服务器账户已有编辑权限。 |
| 播放问题说明 | 播放失败页及更多 → 媒体信息均可打开。根据结构化错误区分授权、网络、解析、解码、画面和声音输出；展示实测缓冲/输出状态并导出诊断 ZIP。未知原因不按报错关键词猜测。 |

接口参考：[Emby 元数据编辑](https://dev.emby.media/reference/RestAPI/ItemUpdateService.html)、[Emby 图片候选](https://dev.emby.media/reference/RestAPI/RemoteImageService.html)、[Plex 图片选择实现](https://python-plexapi.readthedocs.io/en/latest/_modules/plexapi/media.html)。这些参考用于核对请求协议，不能替代实际服务器验证。

## 修复

- 下载通知按整个待执行队列的字节量计算进度，排除历史已完成任务；未知大小显示不确定进度。
- 全部暂停/失败后保留操作通知；通知点击打开下载页，按钮通过 WorkManager 持久化并按顺序执行。
- Plex 单一媒体类型与已看条件下发到服务器，显式排序不再被本地相关度排序覆盖。
- 播放海报过渡遇到零值、NaN 或无穷尺寸时返回有限变换，避免向绘制过程传入无效坐标。
- Harmony 登录与保存服务器不再额外要求 HTTP 确认，继续保留地址格式和同源凭据边界。
