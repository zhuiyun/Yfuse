# 液态玻璃材质预设（L 系列）

入口：设置 → 玻璃材质（手机与 TV 共用）。在原有 01–06、S1–S3 九款之后新增 L1–L6 六款。
参数定义在 `composeApp/src/commonMain/kotlin/com/yfuse/core/designsystem/GlassMaterialPreset.kt`，
渲染沿用 `mutedGlassPanel` 与 `glassMaterialFinish`，没有新增绘制路径。

## 设计思路

原有预设大多靠「雾」取胜（模糊 15–60dp、边缘折射 0–5dp）。液态玻璃反过来：

- **少雾**：模糊半径压低，背景形状仍可辨认。
- **强折射**：边缘折射 5–10dp，面板边缘像透镜一样弯折背景（API 33+ 生效，低版本只保留模糊）。
- **高饱和**：背景色彩透过玻璃后更浓，而不是被雾洗灰。
- **亮边更宽更亮**：亮边宽度 0.8–1.4dp，模拟液体表面张力形成的高光轮廓。

六款按「清 → 厚」「冷 → 暖 → 暗」展开，覆盖浅深两种主题的主要取向。

## 各款要点

- **L1 液态透镜**：全应用最清透的一款。模糊最低（3dp）、折射最强（10dp）、饱和度最高（1.80），配一点点棱镜色让亮边带冷光。
- **L2 晨露水珠**：水青底色加 30% 珍珠柔光，左上角像水珠的受光面，整体水润但不发白。
- **L3 极光釉彩**：棱镜 0.85 + 珍珠 0.20，亮边由青到紫再到暖橙流转；底色是淡薰衣草。
- **L4 冰川流璃**：唯一带纵纹的液态款。模糊 28dp 做出冰的厚度，26dp 宽间距、0.22 强度的纵纹当作冰层里的细纹，1.4dp 的最宽亮边是冰的切面。
- **L5 琥珀蜜糖**：暖金底色加 55% 珍珠柔光，像光透过蜂蜜。浅色主题下比较厚（0.68），保证正文可读。
- **L6 黑曜液镜**：与烟熏墨晶同类，两种主题都是深色面板、浅色文字；但模糊更低、折射和饱和更高，读起来是「黑色液面」而不是「烟雾」。

## 可读性

按设置页同一套估算（纯色页面 + 遮罩 + 面板底色）计算的正文对比度：

| 编号 | 浅色 · 透明 | 浅色 · 实色回退 | 深色 · 透明 | 深色 · 实色回退 |
|---|---|---|---|---|
| L1 | 3.34 | 5.85 | 10.18 | 10.19 |
| L2 | 3.46 | 5.77 | 9.75 | 9.75 |
| L3 | 3.50 | 5.69 | 9.98 | 10.00 |
| L4 | 4.58 | 5.66 | 9.38 | 9.39 |
| L5 | 4.61 | 5.69 | 9.05 | 9.05 |
| L6 | 7.21 | 5.95 | 10.08 | 10.09 |

L1–L3 是薄玻璃，在浅色主题的透明状态下与已有的清水薄璃（3.30）、棱镜流光（3.47）处于同一水平，
设置页会照常给出对比度提示；其余所有情况均达到 WCAG AA 4.5:1。`GlassMaterialTest` 固定了这条底线。

## 实现说明

- 每款预设的全部起始参数（亮边宽度、棱镜、珍珠、纵纹、文字颜色、底色范围、浅色主题色调位置）
  现在都写在 `GlassMaterialPreset` 的条目里，`GlassMaterial` 不再按预设身份分支。原有九款的数值保持不变。
- 存储沿用 v4 命名字段格式，新预设 ID：`lens`、`dew`、`aurora`、`glacier`、`amber`、`obsidian`。
  旧版本读到未知 ID 时，保留用户已调参数并回落到经典玻璃。
- 所有数值都落在滑杆步进上，用户从经典玻璃出发可用滑杆完整重建任意一款（已有测试覆盖）。
