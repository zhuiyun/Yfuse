# 帧率显示

在“高级播放设置 → 显示与音频输出 → 显示帧率”启用。播放中也可通过“更多 → 播放设置 → 画面 → 显示帧率”即时切换。手机和 TV 使用同一偏好，默认关闭，退出后保留；切换开关不会重建播放内核。

普通页面显示页面 FPS；播放器右上角增加实时输出 FPS 与片源 FPS。浮层不接收触摸或遥控焦点，画中画和暂停屏保隐藏播放器浮层。

| 读数 | 数据来源与边界 |
| --- | --- |
| 页面 FPS | Android `FrameMetrics` 实际窗口绘制回调数除以单调时钟的采样时间，约一秒刷新。包含统计文字自身的绘制，不等于屏幕刷新率，也不包含独立视频 Surface 的所有帧。低活动显示 `<2`；回调丢报标记 `~`，不把丢报数补成已绘制帧。 |
| 实时输出 FPS | YCore 的当前输出代有效呈现回调，或软件/GPU 成功提交帧的累计计数；系统内核使用 Media3 的 `renderedOutputBufferCount`。约一秒窗口按墙钟计算，不使用视频时间戳推算，不等于面板最终扫描输出。 |
| 片源 FPS | 当前轨道/内核报告的内容帧率；不是实测输出速度，也不随播放倍速直接改写。未知值显示 `—`。 |

MPV、MDK 和远程投屏当前没有接入可靠的输出累计计数，实时输出显示“暂无数据”。YCore 隧道输出至少收到两个有效帧回调才开始采样；仅报告首帧的设备不能据此测量持续 FPS。暂停、缓冲、播放结束和错误显示对应状态；新会话、拖动及输出重建清空旧样本，超过三秒的样本不再显示为当前 FPS。

开关关闭时页面监听、采集线程及浮层定时刷新全部停止；Activity 离开前台时也释放页面监听。视频统计复用已有输出回调和状态采样，不新增逐帧 Compose 状态推送。

本功能纳入 1.0.74（236）。内核修复后曾暂停打包以补入本功能；暂停前的 APK 不包含帧率显示，不应交付。功能测试及源码一致性记录见 `audit/frame-rate-overlay-20260920/verification.json`，最终交付以 `artifacts/releases/kernel-fixes-1.0.74-236/verification.json` 校验结果为准。

待设备验证：真实播放时三类读数、倍速/拖动/暂停恢复、不同硬件隧道回调、手机刘海与横屏布局、TV 遥控焦点、后台和画中画切换。源码测试不能代替这些设备结果。
