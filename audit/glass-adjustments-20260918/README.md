# 玻璃材质完整调节

用户要求：通过调节功能能调出 01–06、S1–S3 的效果。

- 原有预设变成参数配方。选择预设会填入全部参数，任何预设均可继续调出彩光、珠光、纵纹或平滑雾面，也可以叠加效果。
- 根据用户“14 个滑杆太多”的反馈，默认仅显示雾化、通透度、亮边三项。其余 11 项放入默认折叠的高级调节，按底色、透景、光泽、纹理切换，每组只展示 2–4 条滑杆。文字颜色也放在高级区。
- 通透度按用户语义反向映射底色不透明度：向右更通透。触摸与方向键使用相同数值映射。
- RGB 0–255；模糊 1–70dp；饱和度 0–200%；折射 0–12dp；亮边 0–100%、宽度 0.3–2dp；彩光/珠光/纵纹 0–100%；纹距 4–32dp。
- 底色从原来的灰度范围升级为 RGB 全色调节；旧底色深浅参数仍用于兼容读取，没有丢弃旧设置。
- 预览共用实际弹窗渲染；常规竖屏固定在上方，低高度与大字体下随页面滚动，保证调节区可达。主分段仅保留“材质预设 / 调节效果”，选好预设后自动进入三项常用调节并回到预览位置。
- 每条滑杆支持对应精度的方向键调节。一键重置当前配方，浅深色各自完整保存。
- v3 保存所有参数和文字颜色，兼容旧三参数及 v2 预设格式；数值限制、非有限值回退与旧版默认行为保留。
- 竖纹背景折射的强度、周期和边缘折射彼此独立，表面纹理与 shader 使用同一周期。S 系列不添加噪点。
- 平台限制保持：Android 31+ 支持背景模糊，33+ 支持折射；减少透明度时使用实色回退。

验证脚本：verify.ps1；格式脚本：format.ps1。测试覆盖通过实际滑杆更新函数从经典材质还原九款配方、参数混合、旧设置迁移、异常值以及重启保存。
