# 玻璃材质设置页

入口：我的 → 外观与辅助 → 玻璃材质。TV 外观页也有独立入口；设置搜索可直接找到页面。

- 独立页面，不使用弹窗容器。顶部为浅/深色切换和 232dp 玻璃预览，下方是卡片式参数区及恢复按钮。
- 三条滑杆：底色深浅（显示 RGB 色值）、底色不透明度、背景遮罩不透明度。透明度范围 0–100%，步进 1%；支持触摸、辅助功能调节及方向键。
- 浅色底色从 #878F9B 到 #E4E9F0；深色从 #191E27 到 #878F9B。
- 预览复用 mutedGlassPanel 的模糊、折射、渐变和边框，背景单独捕获，避免玻璃采样自身；背景遮罩单独绘制。
- 设置即时生效并自动保存，浅/深色各自保存。预览的模式切换不会修改应用主题。
- 默认保持现有浅色 #E4E9F0 / 82% / 30%，深色 #191E27 / 72% / 28%；浅色另提供改动前 #878F9B / 52% / 16% 预设。
- 设置应用于统一弹窗玻璃及其遮罩。普通卡片/导航条继续使用原有材质参数。主页面、独立播放器、TV 的主题均提供同一偏好。
- 弹窗直接读取材质设置，海报详情页切换局部 Palette 时也不会丢失遮罩偏好。
- 减少透明度或平台缺少模糊支持时保留现有实色回退，页面提示这一状态；不绕过辅助功能。
- 存储键 appearance.glassMaterial.light / appearance.glassMaterial.dark，每个键存三个浮点参数；损坏值回退，非有限数和越界数归一化。

验证：见 verify.log 和后续最终验证日志。首轮手机编译和 18 项 ThemePreferencesTest / GlassMaterialTest / GlassTest 已通过。编译期间完善了详情页遮罩读取和页面搜索/遥控器入口，最终结果以后续日志为准。
