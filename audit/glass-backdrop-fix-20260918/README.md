# 玻璃弹窗背景采样修复（2026-09-18）

用户反馈：01 及多数玻璃预设下，添加服务器弹窗透出清晰的页面文字，与表单重叠。

## 原因与修改

- YfuseTheme 的 DialogBackdropHost 监听主题层的 OverlayVisibility，但 App 再次创建同名局部状态覆盖它。弹窗只更新内层计数，主题采样层始终认为没有弹窗，因此未录制背景。App 现直接使用主题提供的实例。
- BackdropState.hasContent 原为普通布尔值。采样前首次绘制会提前返回，未订阅帧更新。现通过 BackdropFrames 读取可观察的帧版本，首帧到达与后续录制都会通知绘制消费者。
- 录制计数仍使用普通字段，写入可观察版本时不读取它，避免源绘制订阅自身而持续重绘。
