# 本地验证范围

用户要求不操作手机。本轮不执行 ADB、安装、实机控制、签名打包或上传。

## 必须覆盖的行为

- 已知 Series 首页入口：冷启动实际请求数、目录快照完整时跳过详情、缺字段安全回退、进度投影和下一集语义；未知类型入口保留身份读取。
- 初始轨道：非第一语言音轨实际选中并参与路由；已选音轨/已关闭字幕不重建；真实不兼容选择仍能降级；准备资源和探测缓存不得跨初始偏好错误复用。
- YCore 增强代理：连续/并发 Range 的初始验证复用；身份、强 ETag、长度变化失效；无强 ETag 不信任旧磁盘；一个请求的取消/关闭不污染其他请求。
- 原有探测预算、过期准备源、预热取消、Range 续传与表示隔离、队列补全、播放上报和源切换继续回归。

## 执行与证据

源码修改结束后，统一执行手机/电视主机测试和两端应用编译，并从本轮独立二进制结果生成 HTML 报告，避免共享目录被其他任务覆盖。

继续执行手机/电视 lintDebug、设计规范检查和修改文件的 ktlint；记录编译前后源码指纹。通过后生成 verification.json。

上一轮原生 C++ 与 AAR 本轮未计划改变，使用指纹检查确认。如果发现原生源码必须改变，则需重新构建和验证对应制品，不可沿用旧二进制。

## 弱网日志矩阵（运行测量待后续设备验证）

不调整现有超时常量。后续运行样本需要区分首字节阻塞、传输中断、低速持续进展、高 RTT、小缓冲/足缓冲、预取转前台、seek 取消、ETag 改变、总预算耗尽。

指标包括当前请求耗时/重试次数、范围校验次数、缓存复用/失效事件、tap 到真实首音视频输出、前 30 秒重缓冲。源码和主机测试不能推出实际提速秒数。
