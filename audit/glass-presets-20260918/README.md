# 玻璃材质预设

入口：设置 → 玻璃材质（手机与 TV 共用独立设置页面）。

- 01 清水薄璃、02 银雾磨砂、03 棱镜流光、04 月光珍珠、05 烟熏墨晶、06 纵纹水晶、S1 柔雾、S2 凝雾、S3 乳雾全部加入预设。
- 预设控制背景模糊、饱和度、折射、底色和亮边；棱镜有彩色边缘，珍珠有柔光，纵纹有周期光影及 API 33+ 背景折射。S1–S3 无噪点或砂粒，雾化半径依次为 30/44/60dp。
- 预览和实际弹窗共用渲染。烟熏墨晶在浅色主题下也使用浅色文字，但保留浅色设置的选择归属。
- 选择后立即保存；底色、底色不透明度和背景遮罩滑杆继续微调。浅深色独立记忆，再点同一预设恢复推荐值。原有默认和旧版 52%/16% 恢复入口保留。
- 沿用现有两个设置键，v2 字符串保存稳定预设 ID 和三个参数。兼容旧三参数格式；未知预设保留有效微调参数并使用经典材质，损坏值安全回退。
- 切换预设时，背景折射缓存包含模糊半径与折射参数，防止同尺寸表面沿用上一款效果。
- 遵循“减少透明度”，不支持模糊的平台继续实色回退。Android 31/32 保留模糊及竖纹光影，33+ 才执行竖纹背景折射。
- 仍作用于现有弹窗材质体系；普通卡片与导航条沿用原有样式。
