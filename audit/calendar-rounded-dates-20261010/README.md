# 追剧日历圆角日期块

按用户选定的「圆角日期块」方案替换共享播出日历的日期高亮。

- 已更新：海报主题色的浅色填充，日期与集数使用强调色。
- 待更新：透明底与细虚线圆角边框；明确标记为未播出的当天剧集也保留此状态。
- 当前选中：实色强调色填充，日期与集数使用主题提供的对比色。
- 今天：绿色圆点与隔离底圈，选中后仍然显示。
- 每天独立绘制，取消相邻日期之间的连续毛笔高亮；日期块之间保留间距。
- 保留月份切换、点击展开当天剧集、再次点击收起，以及后续排期列表跳转。
- 无障碍节点保留点击操作和选中属性，并提供已更新/待更新状态。

应用位置：剧集详情的播出日历和追剧日历打开的剧集详情共用 `ShowScheduleCard.kt`。
