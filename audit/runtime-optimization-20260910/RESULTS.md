# 运行时优化与播放器图标调整 · 2026-09-10

用户选定的优化项已落实到工作区，另按参考图调整了选集、弹幕图标。未连接手机，未执行 ADB、设备测试、签名打包或上传。

## 已完成的修改

| 范围 | 实现与行为 |
| --- | --- |
| 播放诊断 | 先比较报告输入，再构建和脱敏；位置变化不重复生成相同报告。报告移至单个后台工作协程，队列只保留最新快照；序号防止旧播放器的收尾任务覆盖新报告。 |
| 轨道列表 | 缓存状态映射；只有音轨、字幕列表内容变化时才重新映射，播放位置更新复用已有列表。 |
| 弹幕 | 逐帧位置读取移至布局偏移和图层透明度计算；组合层仅随时间窗口变化更新，保留原有时间插值和恢复逻辑。 |
| 库页 | 缓存 JSON 只解析一次；缓存读取、解析、较重转换与写入在工作线程执行；结果仍检查请求代次与服务器归属。缓存失败记录日志并继续加载在线内容。 |
| 冷启动 | 崩溃记录读取、凭证恢复在后台完成，依赖登录状态的界面保留恢复门禁与重试入口；同步及健康监测延后到首屏帧边界后启动。 |
| 缓存存储 | 手机与 TV 的库页/TMDB 首页缓存迁往独立 SharedPreferences，按需打开；持久复制成功后才清理旧键；服务器移除、导入、退出后清理孤立库缓存。 |
| 异常与进度可靠性 | HTTP 代理意外停止接受连接时记录异常；离线队列因容量限制丢弃播放结束记录时持久累计，并在应用界面提示。确认提示只扣除用户已看到的数量。 |
| 首页刷新 | 日历请求合并并检查代次；再次进入页面沿用缓存策略，短时间重复进入库内容不再次请求；主动刷新和重试仍可触发更新。 |
| 预览拼图 | Android 使用区域解码器解码当前单格，并按目标尺寸采样；图片请求保留原 URL 的磁盘缓存，内存缓存区分格子。 |
| HTTP 客户端 | AccountApi、PlaybackCloudApi、QoeReporter、OfficialAiringScheduleCatalog 复用同一个具名账户客户端；不同配置的媒体及 TMDB 客户端继续按用途配置。 |
| 构建与维护 | 忽略临时 Gradle、工作树和审计备份目录；六个校验任务声明成功输出和验证逻辑输入；删除确认无调用的旧播放器控件；将播放器诊断绑定与来源日志从 PlayerRoot 抽出。 |
| 选集与弹幕图标 | 选集为三行圆点列表，弹幕为带矢量“弹”字的对话框；与字幕、音轨使用相同的 26dp 圆形按钮、12dp 图标、白色圆角描边。移除这两个按钮的外部文字标签，保留可访问名称及弹幕开启提示与淡色高亮。 |
