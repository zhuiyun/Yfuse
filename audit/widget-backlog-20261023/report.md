# 自定义首页已选组件实现记录

依据共享会话与「Yfuse 自定义首页组件开发待办」中的 21 种已选布局实施。基线为实际交付的 1.6.4 / 316 源码记录；本轮为代码开发，不生成安装包。

## 新增样式

| 类型 | 样式 | 实现 |
| --- | --- | --- |
| 动态构图 | 叠层海报、折页片单、弧形海报、书脊片库、纵深片廊、折屏画廊 | WidgetKineticLayouts / WidgetKineticGeometry |

总样式由 42 种增至 63 种，沿用现有添加、预览、配置、排序、隐藏及持久化流程。所有首页布局高度有界；组合及集数网格在固定行数内横向分页。具体影视进入详情页，原生媒体库集卡进入对应集详情。

剧集资料按真实 TMDB 标识匹配当前资料可访问的媒体库；下一集由真实 nextUp 与可用集交叉确认。观看状态以本机 PlaybackSyncStore 为权威，未知状态保持未知。原生导航目标由宿主生成，脚本 JSON 不可伪造。编辑器示例不访问媒体库。

## 现有问题

- 杂志布局继承 1.6.4 的固定横向高度和文字空间修复，复核图片、徽标、标题、评分、简介均在测量边界内。
- 已配置栏目不再被临时内容的 48 项缓存驱逐；临时浏览仍有上限。修改参数及删除页面会清理对应旧内容。
- 每个自定义页面独立保存滚动与浏览状态；刷新期间沿用已有内容和请求取消保护。
- 分季选择用独立标记区分未选择和未标注季；矩阵按实际字体行高、两行集卡、筛选及重试区预算最小高度。
- 原生后台请求把结果与失败作为缓存值传递，由调用端统一处理异常；网络失败保留来源内容并允许重试。
- 播放记录缺少总时长时，可使用媒体库真实时长计算进度；清空本地记录后不恢复旧缓存的观看状态。
