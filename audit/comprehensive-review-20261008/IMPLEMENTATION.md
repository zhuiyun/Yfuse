# Yfuse 全项目复查与修复记录

审查日期：2026-10-08。范围包括手机、TV、共享业务、自有后端客户端、协议与服务端、投屏接收器、原生核心、Harmony 移植和验证脚本。本轮在前次后端隔离、详情手势与可预测返回修复之上继续修改，保留现有未提交工作。

已将确认的缺陷落实为代码修复和针对性回归，并把焦点恢复、遥控令牌刷新和日历网络地址策略提取为独立组件。检查覆盖主要用户路径、状态与资源边界，不等于所有设备、媒体格式和生产部署都已完成验收。

## 已修复问题

| 优先级 | 问题与触发条件 | 具体改进 | 预期效果与回归 |
| --- | --- | --- | --- |
| P1 | 连续瞬时音频焦点丢失覆盖自动恢复意图；缓冲状态也可能丢失意图 | 提取 `PlayerAudioFocusState`，按播放请求而非正在出帧记录恢复意图 | 来电等中断结束后保留正确恢复意图；纯状态机覆盖重复中断和缓冲场景 |
| P1 | 焦点恢复可唤醒正在退出、后台、投屏或已手动暂停的本地播放器；旧回调可污染新请求 | 恢复统一经过生命周期策略，退出动画开始即放弃焦点；手动暂停取消恢复；按请求代次忽略旧回调 | 防止退出后继续发声、违背暂停操作；状态机、生命周期及真实 gate/adapter 回归 |
| P2 | 生命周期暂停的一次性标记忽略引擎迟到恢复；暂停起播仍抢占其他音频 | 允许生命周期再次暂停迟到播放；只有实际请求播放才申请起始焦点 | 减少后台误播及暂停打开影片时对其他音频的干扰 |
| P1 | 遥控登录续期异常逃出连接循环，手机停留连接中，TV 生命周期观察任务退出 | 提取 `RemoteTokenRefresh`，区分续期成功、登录过期、暂时不可用；取消继续传播 | 手机有正确的重试/重新登录提示；TV 按退避恢复且可重新激活 |
| P1 | Trakt 断开或重连后旧请求仍导入；令牌刷新期间关闭上报，刷新后仍发送 | 增加授权代次，异步返回与发送前重新核对授权、开关和队列归属；失效单次任务不杀死重试循环 | 防止旧授权结果写入和关闭后的新上报；延迟 API/刷新回归 |
| P1 | 清理个人设置途中切换资料，逐项删除使用新的资料前缀 | 在清理开始时固定完整键集合 | 不误删其他资料设置；切换资料回归 |
| P2 | Trakt 标题按 512 字截断，但个人库只接受 240 字，导致长标题一直导入失败 | 统一个人媒体标题上限，复用于 Trakt、媒体服务器与 TMDB 转换 | 长标题可合法入库；使用真实个人库的导入回归 |
| P1 | 接力缓存仅以密文为键，另一设备条目复用相同密文会跳过设备身份 AAD 校验 | 解密缓存键包含设备会话 ID 与密文 | 继续缓存合法重复心跳，同时拒绝跨设备重放；身份重放回归 |
| P1 | 房间加入失败计数及处罚条目可以无限增长；并发乱序时间可能破坏清理策略 | 两表合计容量有硬上限，满载拒绝新身份，保留现有保护；以锁内单调有效时间处理计数和到期 | 控制内存并保留处罚；容量、到期和乱序时间回归 |
| P1 | 日历浏览器子资源地址过滤遗漏 IPv6 私网、映射地址及 localhost 别名 | 提取 `network-policy.mjs`，统一 URL/地址规范化与过滤 | 关闭这些地址形式的绕过路径，保留公网 CDN；不把 URL 过滤等同于 DNS/网络出口隔离 |
| P1 | 日历容器浏览器镜像 1.62.1 与 Playwright 包及锁文件 1.63.0 不一致 | 对齐镜像版本并检查相对运行模块是否复制进镜像 | 避免缺浏览器或缺模块导致启动失败；部署契约回归，真实容器仍需部署验证 |
| P2 | 投屏 LOAD 的 HTTP 前缀正则接受无主机、非法 IPv6 或端口 | 使用 URL 解析校验，继续接受用户局域网媒体地址 | 尽早返回无效加载错误；接收器行为回归 |
| P1 | 原生内核输出设置失败仍保存被拒绝的输出指针 | 仅成功后更新输出缓存 | 切换引擎时恢复上一次接受的输出；新增 native 行为用例 |
| P1 | 原生手动重试清空尝试集合后未记录当前引擎，后续回退重复开启同一引擎 | 将已执行专用重试的引擎加入本轮尝试集合；缺少接口或返回不支持时保留关闭后重开 | 回退继续选择其他引擎，同时保留单引擎重试；覆盖成功、真实失败、缺失接口、不支持及进度恢复 |

优先级表示修复价值；表中效果是对应行为目标，不是未经测量的性能增幅。

## 结构调整

- `PlayerAudioFocusState` 承担与平台无关的焦点状态转移，`PlayerAudioFocusController` 负责 Android API；`playerPlaybackAllowed` 统一用户播放和异步恢复资格。
- `RemoteTokenRefresh` 统一手机与 TV 的令牌续期结果，保留各自适合的恢复方式。
- `network-policy.mjs` 集中日历浏览器地址策略，直接进行地址变体测试；部署测试验证运行依赖。
- 统一个人媒体标题上限，避免多个数据来源与存储校验各自维护常量。
- 继续保留 `yfuseBackendClient` 的独立依赖与开关，不为本次修复重新耦合媒体客户端和自有后端。
