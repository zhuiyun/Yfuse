# 产品改进实施与验收

## 范围

按用户确认，实施对比报告的 O1–O8、N1–N4、N6，共 13 项。N5 NAS / 本地视频来源不实施。用户确认 Trakt 尚未注册，先完成可配置接入代码。

本轮没有播放视频、发起投屏、一起看开播、创建实际下载任务、执行真实 Trakt 授权或写入第三方。没有生成交付 APK、安装、推送或部署；版本配置保持原值。

## 额外修复的边界问题

| 严重度 | 问题 | 修复与验证方式 |
| --- | --- | --- |
| P1 权限 | Plex Home 的 PMS 所有者名称可能令不同家庭用户共用保存身份，儿童关联继承家长凭据。 | 云/Home 绑定 Plex 验证的活动用户；手动 Token 使用用途隔离摘要，保留局域网直连；4 项身份隔离行为测试。 |
| P1 权限 | 不可访问的显式服务器退回默认服务器、旧播放器及下载列表未及时收紧范围。 | 取消静默回退；队列启动/资料切换校验；手机与 TV 下载过滤及批量操作限制。 |
| P2 正确性 | 旧资料的同步/提醒回包或待写回队列影响当前资料；容量超限可能抛出未捕获异常。 | 固定资料归属、保留其他资料队列、保存失败保留原数据并显示状态；个人仓与真实加密 HTTP 合并测试。 |
| P2 正确性 | 内核先 Ready 后报告轨道，导致接力偏好提前丢失；相同标签的多条轨道无法消歧。 | 固定最多 10 秒等待，缺失项明确提示；仅同一物理版本使用经过元数据核对的索引；6 项新增测试。 |

- 明确指定但不可访问的服务器不再退回默认服务器，避免同一条目编号指向其他用户内容。
- 播放入口验证队列权限；切换资料或撤销权限时关闭旧播放器并清空旧导航/搜索状态。
- 手机和 TV 下载列表及批量操作仅涉及当前资料可访问的服务器；儿童资料不能修改全局下载策略。
- 旧资料的异步历史、日历、提醒和服务器同步回包不能写入新资料；其他资料的写回队列保留，待切回再处理。
- 个人清单使用带删除标记的合并，旧设备不会复活已删除项目；容量达到上限时保留原数据并提示。
- 接力仅向前台空闲设备开放接收；App 在后台且没有活动播放器时停止接力心跳。不同服务器副本需要已知且相近的时长，才能复用绝对进度。
- Trakt 播放上报固定账号与资料归属，旧播放器退出时的迟到回调不能写入新资料。

## 家庭资料使用方式

1. 各设备登录同一个 **Yfuse 主账号**。
2. 手机进入“我的→家庭资料→新建”；TV 进入“我的与设置→家庭资料”。儿童资料需先设置家长 PIN。
3. 编辑资料并勾选其可使用的媒体服务器用户。需要服务器端观看记录也独立时，先在媒体服务器创建不同用户，再分别添加并关联。
4. 在“同步状态”执行“合并同步 / 重试”，同步资料、个人清单、历史及追剧。
5. 服务器地址、保存的登录凭据及设置沿用“账号与同步”的加密快照上传/恢复；新设备需恢复配置。离线视频和缓存不随云同步传输。

当前设备选中的家庭资料是本机选择；手机可选择家长资料，平板可选择另一资料。“手机房主、平板观众”不要求建立两个家庭资料，一起看角色按设备区分。

## 上线与能力边界

- 新接力及 Trakt 后端路由尚未部署；Trakt 还需注册开发者应用并设置服务端环境变量。Secret 不进入客户端。详见 [接力与 Trakt 配置](handoff-trakt-changes.md)。
- 个人数据合并与服务器配置快照由用户明确触发；播放进度保留自动同步及前台恢复。相同媒体服务器用户的服务端状态仍共享，PIN 不替代服务器授权。
- Plex 云/Home 切换及手动 Token 更换后可能生成新的保存身份，需要重新关联家庭资料；旧儿童资料不会静默继承新用户的权限。
- 个人数据沿用现有快照容量约束，当前最多 24 份资料、1,000 条条目及 1,000 条追剧记录，均包含删除记录。服务器清单导入目前支持 Emby/Jellyfin；Plex 批量清单导入未增加。详见 [个人资料实现](personal-changes.md)。
- 没有进行新包实机 UI、遥控器遍历、真实跨设备接力或真实 Trakt 授权验收；不据静态检查声称已验证播放流畅性或所有媒体格式兼容性。
