# 动效状态与绘制优化 · 2026-09-10

本轮按用户选定的四组项目修改，保留当前工作区其他功能。源码清单见 `changed-files.txt`，修改前副本位于本目录的已忽略 `before/`。

| 范围 | 本次修改 |
| --- | --- |
| 加载光球 | 动画状态以 State 引用传入 Canvas，仅绘制读取旋转与呼吸值；应用内减弱动效开启时不创建无限动画通道。光球的几何、色调与周期保持原参数。 |
| 详情顶栏 | 返回/更多按钮使用相同的矢量图案、命中区域和可访问名称；滚动驱动的图标色、玻璃填充、描边和背后颜色改为绘制时读取。固定与动态液态玻璃共用同一组绘制公式，兼容毛玻璃、降低透明度和弱化玻璃状态。 |
| ASS 字幕 | 删除组合层逐帧更新的时间 Pair；帧时钟直接提交给现有异步 ASS 渲染器。只有活动字幕集合或实际位图变化才通知字幕组合。保留混合 ASS/文字双轨时钟、延迟、倍速、暂停、时间轴代次、字幕缩放与双字幕布局。 |
| 主题 | 主题过渡返回 State，由局部颜色提供器读取；动态色值使用跟踪读取的 CompositionLocal，静态无障碍、密度和玻璃设置不再与逐帧颜色捆绑更新。修复动画途中启用减弱动效时同一目标色无法立即落定的问题。 |
| 页面强调色 | 将语义目标色与中间动画帧分开。详情页/TMDB 页面主题随目标更新，需要渐变的内容由局部 AnimatedColorContent 接收；播放器强调色直接由进度条绘制读取。 |
| 播放器重复计算 | 按队列内容缓存剧集卡片；按片头/片尾边界及总时长缓存进度标记，倒计时变化不重建标记。进度/缓冲轨道保持固定布局，通过绘制宽度展示比例，保留拖动、章节吸附、键盘和可访问语义。 |
| 库首页 | carouselVisible 改为 derivedStateOf；只有“首项可见且未滚动”的布尔结果变化时才通知页面，不随不相关的跨条目状态变化更新。 |
