# 健康检查修复记录（2026-09-20）

本次在已有未提交修改上继续修复健康检查发现的问题。没有执行 APK 打包、安装、部署、提交或推送；没有为本次修复递增版本配置。工作区原有的 Android 17、玻璃材质与播放性能改动予以保留。

HTTP 说明：用户输入的媒体服务器仍接受 HTTP/HTTPS，Android 的基础网络配置允许明文。
本次响应大小限制只应用在服务端日历采集、OCR 和渲染响应，没有限制媒体视频流。
账号、更新和指定元数据服务原有的 HTTPS 策略不变。

## 已实现

| 问题 | 修复与边界 |
| --- | --- |
| 云端配额淘汰后，客户端持有过期游标而持续无法上传 | 协议增加明确的 `missing` 回复；客户端只对匹配的实体、变更与旧游标重置上传基线，保留本地待上传数据，重建仍经过并发冲突检查。旧服务端空回复转为可观察的无进展错误与退避。自动恢复需要同时更新服务端。 |
| 永久失效的播放会话堵塞同服务器后续上报 | 对真实 HTTP 404/410 隔离该会话的未送达事件，继续处理其他会话；持久保留告警和有限重试材料。用户可重试；“稍后提醒”只推迟当前进程的显示。重试不能保证恢复已过期的远端会话。 |
| 切版本、切服务器等待旧转码清理期间覆盖新的播放意图 | 共享切换协调器，核对队列、媒体、会话与实际内核身份；手动/远端播放请求令旧操作失效。普通进度变化、Seek 和输出路由重置保持同片切换有效。 |
| 上游响应在检查长度前已完整载入内存 | 日历抓取的字符串响应在接收字节时计数，超限取消订阅；保留原有字符限制和 UTF-8 内容兼容。 |
| 渲染排队无界、超时与断开未覆盖完整生命周期 | 最多 2 个活动任务与 8 个等待任务；25 秒总期限包含排队；断开或超时关闭 context，清理后释放名额；健康检查反映浏览器连接状态。浏览器断开仍需要重启 sidecar。 |
| Cast 新加载可能复用旧媒体状态 | LOAD 重置确认状态，只接受与当前 `yfuseRevision` 对应的媒体输出证据；增加旧状态、稀疏状态回归测试。 |
| Emby 标识符直接拼接 URL 路径 | 相关数据服务、图片与流地址统一使用现有 `embyPath`；测试特殊字符、Unicode、字面 `%2F` 与服务器子路径。 |
| 依赖已知风险 | BC 家族固定到 1.85；Wire runtime 固定到 6.4.5；测试工具链 commons-lang3/httpclient 固定到 3.18.0/4.5.14。通过 Gradle 更新受影响锁记录；协议模块旧 serialization 1.7.3 锁记录与现有 1.8.0 配置对齐。 |
| npm 依赖未进入供应链检查、镜像安装未使用锁文件 | 扫描受 Git 管理的 npm 锁文件，包含传递/可选/作用域依赖，沿用失败即阻断策略与 SPDX 输出；增加 npm Dependabot 与锁文件安装。 |
| lint 工具依赖绕过版本覆盖 | 实际运行发现 AGP 的 detached configuration 仍请求 BC 1.79。增加读取同一覆盖清单的组件依赖规则，让临时工具链的传递依赖也使用补丁版本；保留现有配置解析规则。 |
| CodeQL 未提取 Kotlin | 改为手动构建模式；在初始化前准备原生依赖，初始化后实际编译手机、TV、协议与服务端 Kotlin。配置语法已验证，远端提取与上传尚未执行。 |
| 文档与源码边界说明 | README 区分已交付包与源码 SDK 状态；补充渲染队列、超时、健康检查与重启说明；TV 源文件的原始 NUL 改为等价转义。 |

最新全量轮次的手机测试为 2,790 项、3 项失败，均在期间更新的播放逻辑测试中：

不能仅凭该错误断言业务代码有缺陷。当前完整状态见 `verification.json` / `final.log`；
本轮直接修改范围的独立回归结果见 `focused.log`，两者分别记录。

专项验证最终通过 Gradle `--tests` 运行 7 个目标测试类，**68 项全部通过**，实际 XML 快照保存于
