# 追更推送只通知手动订阅

日期：2026-10-10。

用户要求：只推送自己订阅的剧集，避免所有剧集都推送；截图同时出现播出时间调整为 `null` 的文案。

原因：媒体库剧集会自动成为 `LibraryAuto` 追更，原来默认开启新入库提醒；排期变更通知虽然按追更 ID 过滤，却没有区分自动追踪与手动订阅，也没有遵守关闭提醒的设置。后台查询前保存的订阅快照还可能在取消订阅后继续使用。

已修改：

1. 推送资格统一为当前账号／资料下 `Manual` 手动订阅且提醒模式不是 `Off`，覆盖排期变更、播出前、播出时和新入库提醒。
2. 新增的媒体库自动追踪默认关闭提醒；旧版保存的自动追踪即使仍带有开启模式，也不能推送。日历中的自动追踪保留。
3. 用户单独为自动追踪条目开启提醒时，转为手动订阅。批量开启只影响手动订阅；批量关闭也清除旧自动追踪的提醒模式。
4. 提醒任务不再为推送自动添加整库追更。查询后在账号／资料锁内重新读取有效订阅，取消订阅、关闭提醒、切换资料或账号后，旧任务不能继续通知。
5. 没有有效订阅时取消下次提醒闹钟并结束任务，不查询整份提醒日历。
6. 播出时间缺失显示为“待公布”；只变更时区时显示具体时区。旧缓存通知与日历文案同样兼容，保留原始消息作为去重依据，避免修正文案后重复提醒同一次调整。
