# 弹窗动画选择

入口：设置 → 更多外观与辅助 → 弹窗动画。设置搜索支持“弹窗”“动画”和动画名称关键词。TV 设置中的“弹窗动画”按确认键依次切换。

六种样式：柔和浮起（默认）、中轴展开、底部升起、触点展开、柔性回弹、轻透视展开。选择立即保存，可打开预览弹窗查看进入与退出。

- 通用 GlassDialog 与播放器 PlayerPopupPanel 共用几何动画；没有弹窗透明度动画。
- 页面和弹窗根节点记录点击位置，触点动画围绕该位置展开；键盘输入清除触点，退回居中展开。
- 已经打开的弹窗保留原动画，避免选择时跳变。下一次打开使用新样式。
- 保持深色玻璃材质；“减少动画”直接完成显示和隐藏。
- 关闭动作完成退出动画后执行，兼容进入时快速关闭和重复关闭。
- 配置使用 appearance.dialogAnimation 保存枚举名称，未知值回退默认样式。

最初实现阶段只生成独立调试测试包；正式签名交付见下方 1.0.39 记录。

验证：完整构建、ktlintCheck、verifyDesignSystemUsage 通过；2018 项单元测试通过，无失败或跳过。原生引擎校验清单在构建后已恢复。

## 科幻动效扩展

新增全息扫描、空间折叠、能量边框、分层悬浮、光圈展开、数字重构，共十二种样式。原有默认值及保存名称保持不变。

- 全息扫描用移动的裁切边缘和两条细扫描线展开面板。
- 空间折叠将面板按中央折线分成两翼，通过压缩与轻微角度变化展开。
- 能量边框先绘制四角边线，再从中心展开内部。
- 分层悬浮分别处理玻璃底板、标题和正文的位移与缩放。
- 光圈以实际点击位置为圆心，半径覆盖最远角；光环限制在弹窗范围内。
- 数字重构使用六条固定切片、交替位移和少量错峰；完成后恢复单次正常绘制。

所有光效只出现在过渡期间；进度端点直接隐藏或正常绘制，不改变弹窗透明度。选择窗口分组滚动，预览和完成按钮固定在列表外。
