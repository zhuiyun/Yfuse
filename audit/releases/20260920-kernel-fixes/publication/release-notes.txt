1.0.74

• 新增“显示帧率”开关，区分页面绘制 FPS、视频实时输出 FPS 与片源 FPS；设置即时生效并保存，未取得输出样本时明确显示暂无数据。
• 修复原盘软件解码回退未生效及重复重试，补齐多角度切换和播放器释放交接。
• 优化自研内核拖动进度、切换音轨时的读取中断与恢复；超时先反馈失败，旧资源释放完成后再启动替代内核。
• 修复切换内核及播放策略时丢失暂停、进度、倍速和队列意图的问题，避免旧实例清理覆盖新实例的崩溃记录。
• 修复 MDK 加载新流时被旧错误状态提前终止的问题，并使音频诊断对应当前选择的音轨。
• 限制本地播放代理的活动连接及请求头读取期限，补齐音视频元数据和字体附件的分配边界；媒体响应大小、Range 偏移及播放时长不受新增请求头限制影响。
• 改为按需分配播放暂存缓冲，将软件解码和渲染占用计入缓存预算；更新自研原生运行库与构建校验。
• 同步当前 Android API 37 目标配置，保留自定义媒体服务器的 HTTP 访问兼容。
