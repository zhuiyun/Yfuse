# Yfuse 1.0.46（208）

Android arm64 安装包，使用原正式签名。

- 新增搜索等待光晕、完成扫光和首批结果分层显现；翻页不重复播放。
- 新增底部导航拖动形变，松手吸附并切换页面，取消手势保持当前页面。
- 新增“我的 → 更多外观与辅助 → 搜索与导航动效”开关，默认开启，关闭设置会保存。
- 遵循“减少动画”和“减少透明效果”设置。
- 包含此前的字幕、播放探测、诊断及在线更新修复。

本次不包含仍处于讨论阶段的 Finly 面板动画。TV 页面沿用提交 `805af51c81247e87de6e1a0ee10101b97c64e990` 的基线；工作区未完成的 TV 页面没有被覆盖，也没有打入此包。

动效和设置的 15 项单元测试、三星 SM-G973U 上的 3 项测试均已通过。签名、包信息、16 KB 对齐、8 个原生库一致性及 SHA-256 校验结果见同目录 `verification.json`。

本次构建使用 `yfuseVersionName=1.0.46`、`yfuseVersionCode=208` 参数覆盖版本，仓库中的版本元数据未更改。
