# Yfuse 1.0.48（210）

Android 手机 Full / arm64-v8a 包，沿用现有正式签名配置。

- 修复多个服务器陆续返回搜索结果时，列表重排导致已出现卡片再次变透明、向下回跳的问题。
- 聚合结果和按服务器显示的分组都按稳定 ID 保留本轮首次入场延迟；动画结束后清空延迟缓存。
- 搜索等待动画的时长改用命名常量，保持原有时长和视觉效果。

本次构建使用固定的手机端 Kotlin 源码快照。TV 页面延续上一版手机包采用的提交
`805af51c81247e87de6e1a0ee10101b97c64e990` 基线。完整构建参数见 `build-release.ps1`，
源码文件及校验值见 `source-hashes.json`。

Release 环境下的搜索过渡、底栏动画、加载动画和主题设置共 23 项单元测试通过。
本次未进行设备安装或实机动画回放。最终签名、版本、对齐、原生库和 APK 校验结果由
`verify-release.ps1` 验证后写入 `verification.json`。

版本通过 Gradle 参数覆盖为 `1.0.48 / 210`，仓库的 `version.properties` 未修改。
