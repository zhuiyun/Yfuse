# Yfuse 详情页 UI 审查

> 截图证据已迁移到 `repository-binaries-before-cleanup-20260821.zip`；文件名保持不变，
> 归档校验值见 `audit/README.md`。

## 审查范围

- 页面顶部海报、信息摘要及首屏层级。
- 滚动后的片源、剧集列表与固定操作区。
- 液态玻璃一致性、可读性和触控风险。

## 结论

当前详情页的主要问题不是“玻璃效果不够”，而是 TMDB 详情与媒体库详情使用了两套不同的信息结构。顶部大图有冲击力，但内容衔接过白、嵌套圆角过多；下半页片源卡空、剧集列表过长，主操作与次操作缺少统一层级。

## 证据与建议

### 1. 顶部海报与摘要区 — 一般

证据：`03-detail-current.png`

- 优点：海报占比足，首屏识别度高；返回按钮位置明确。
- 问题：白色渐变覆盖范围过长，海报下半部发灰；大玻璃卡内部又套一层圆角状态框，形成“圆角套圆角”；无媒体库资源提示占据主操作位但不可操作。
- 建议：将海报高度控制在屏幕的 55%–60%，底部用短而深的 160–220dp 渐变；摘要卡只保留一层玻璃容器；把“未加入媒体库”缩成辅助标签，不占整行按钮高度。

### 2. 主操作区 — 较差

- 播放、收藏、下载、标记已看在不同状态下位置不一致，滚动后顶部还出现接近透明的操作文字。
- 建议：在海报与内容交界处固定一条单层玻璃操作坞。播放使用宽胶囊主按钮；收藏、稍后观看、下载、更多使用统一 48dp 图标按钮。滚动后只把这条操作坞压缩成固定标题栏，不重新绘制另一套按钮。

### 3. 简介与片源 — 一般

证据：`04-detail-lower-current.png`

- 简介行长、颜色偏浅，扫读压力大。
- 片源卡高度偏大但信息很少，服务器名、码率、大小之间没有清楚的选择状态。
- 建议：简介默认 3 行并提供“展开”；片源改成横向紧凑玻璃卡，结构固定为“服务器名 / 码率 · 大小 / 当前勾选”，选中只在右上角打勾，不改变底色。

### 4. 剧集与演员结构 — 较差

- 当前剧集纵向长列表会把演员与相关推荐推得很深，与既定的“剧集横排、演员在下”不一致。
- 建议：季选择器放在标题右侧；剧集使用横向 16:9 卡片，每卡显示集号、标题、时长与进度；演员紧接其后横向排列，再放相关推荐。

### 5. 视觉系统与无障碍 — 一般

- 页面同时出现纯白、浅粉、蓝边框和不同透明度玻璃，缺少同一材质规则。
- 浅灰文字、接近透明的顶部操作在亮背景上对比不足；状态栏白色图标在高亮海报区域也有风险。
- 建议：底色保持中性纯白；玻璃只使用三档透明度（强/中/弱），强调色从海报取色但只用于播放进度、评分和选中勾；正文至少 14sp，次级信息至少 12sp，并根据海报亮度实时切换状态栏和返回按钮前景色。

## 推荐页面顺序

1. 55%–60% 高度背景海报与返回按钮。
2. 单层悬浮玻璃摘要卡：小海报、标题、类型/年份/时长、评分。
3. 单层玻璃操作坞：播放、收藏、稍后观看、下载、更多。
4. 三行简介。
5. 横向片源卡。
6. 季选择器与横向剧集。
7. 横向演员。
8. 相关推荐。

## 证据限制

截图能确认视觉层级、布局和对比度风险，但不能确认 TalkBack 朗读顺序、触控目标实际尺寸、焦点行为、动态反色速度和共享元素动画是否流畅；这些需要真机交互测试。
