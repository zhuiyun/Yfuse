# YCore 手动重试修复验证

日期：2026-10-16

## 问题与修复

增强探测会缓存片源打开失败 30 秒。原来的手动重试虽然重建播放链路，却没有清除这份失败缓存，可能直接再次抛出旧的网络错误，而没有重新打开片源。

现在执行重试命令时清除失败缓存和上一轮平台探测记录，并重新建立探测预算。缓存使用重试代次校验，旧探测晚到的结果不能写回新一轮缓存；成功的媒体元数据仍可复用。现有播放器释放顺序保持不变。

- `:phoneShared:testAndroidHostTest`：865 个测试套件、4902 个测试，失败、错误、跳过均为 0。
- `:composeApp:compileDebugKotlin`：通过。
- `git diff --check`：通过。
- Gradle 验证总耗时：7 分 19 秒，完整输出见 `validation.log`。

新增行为测试验证了立即手动重试确实重新打开片源、成功元数据继续复用，以及旧探测延迟失败不会阻止新尝试。对应套件的 10 个测试全部通过，原始结果见同目录 XML。
